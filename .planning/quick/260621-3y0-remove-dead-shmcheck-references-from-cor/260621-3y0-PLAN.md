<objective>
Remove the orphaned/dead ShmCheck references from `Apps/CortexMac/ContentView.swift` so the CortexMac target compiles again.

`ShmCheck.swift` was intentionally deleted from CortexCore in Phase 2 (commit d1612d9, "remove ShmCheck IPC-03 SC#2") when the real mach_msg/fileport IPC superseded the Phase-1 SC#2 demo. `ContentView.swift` was never updated and still references the deleted `ShmCheck` enum and `ShmCheckResult` type, producing two hard compile errors ("Cannot find 'ShmCheck' in scope", "Cannot find type 'ShmCheckResult' in scope"). This orphaned reference is the ONLY thing blocking CortexMac from building — signing (`DEVELOPMENT_TEAM` = 57YW6M29S7) and module deps are already fixed.

Purpose: Unblock the CortexMac build with pure dead-code removal in a single file.
Output: A cleaned `ContentView.swift` whose remaining UI is the valid title/App-Group/SHM/container labels.
</objective>
