<threat_model>
## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Host UI state → Scan-Info OUTPUT report → round trip | The host's selectedItem/numberOfItems/seed cross into the decode loop; a malformed count could index out of bounds | scan-cycle UI state (in-process, non-sensitive) |
| Round trip → Item-Selection/Pointer INPUT report | The returned intent crosses back to the host; an out-of-range itemIndex or pointer delta would be an invalid report | intent (item focus + cursor delta) |
| Round trip → instrumented log | The log is the SC#2 evidence; a fabricated or empty log would forge the closed-loop claim | timestamped cycle entries |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02-01 | Tampering / DoS | A Scan-Info report with numberOfItems=0 or an out-of-range selectedItem causing an out-of-bounds focus index | mitigate | `itemIndex` clamped to `0..<max(1, numberOfItems)`; the numberOfItems=0 degenerate case returns a safe no-selection intent (Test 5) — no crash, no OOB |
| T-08-02-02 | Spoofing / Repudiation | A fabricated or empty round-trip log presented as the closed-loop proof (SC#2) | mitigate | The log is GENERATED by `respond(to:)` (one entry per cycle, regenerate-from-code provenance); a test asserts exactly one entry per call with the seed + in/out items recorded; Plan 03 surfaces the live log in the demo + the Plan 06/evidence cites it |
| T-08-02-03 | Tampering | Non-determinism (RNG/wall-clock) in the intent computation letting the round trip be unreproducible | mitigate | The intent is a pure function of the Scan-Info input (no RNG/Date in the intent path — grep-asserted); timestamps via mach_absolute_time are confined to the LOG, asserted monotonic not exact |
| T-08-02-04 | Information Disclosure | (n/a) no PII, no secrets, no network — synthetic UI state only | accept | In-process host harness over public protocol report shapes; no sensitive surface |
</threat_model>
