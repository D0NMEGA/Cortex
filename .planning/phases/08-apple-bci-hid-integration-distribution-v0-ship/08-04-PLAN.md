| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| ASC .p8 private key + key-id + issuer → notarytool/fastlane | The JWT signing key crosses into the pipeline; a committed key is a credential leak | ASC API key (SECRET — env-only, never committed) |
| MATCH_PASSWORD + private certs repo → match | The match passphrase + the signing certs cross into match; a public-URL certs repo or a literal password leaks them | MATCH_PASSWORD (SECRET) + signing certs |
| Source tree → notarize-policy.sh / match-policy.sh gates | The gates prevent a future commit reintroducing altool, a file:// or public certs URL, or a literal password | source diffs |
| CI → Apple (notarytool/TestFlight) | CI must NOT contact Apple (no enrollment, no key) — a live lane in CI would fail or leak | (must be absent) |
