<!-- The exact public C report structures to port (RESEARCH §1.1 — port these VERBATIM into Swift).
     Usage Page 0x60 = "Brain Control Interface"; Usage 0x01 = BCI Application. -->

```c
// RID 1: [0]=buttonID, [1..2]=signalQuality (neural strength 0-255, Usage 0x02)
typedef struct { UInt8 reportId; UInt8 signalQuality[2]; } BCIInputSignalReport;
// RID 2: 32 buttons over 4 bytes (HID Button Usage Page)
typedef struct { UInt8 reportId; UInt8 buttons[4];       } BCIInputButtonReport;
// RID 3: x,y,z deltas -127..127 (Generic Desktop) — THE cursor/pointer report
typedef struct { UInt8 reportId; SInt8 position[3];      } BCIInputPointerReport;
// RID 4 (input): focus item 0..255 (BCI Usage 0x04)
typedef struct { UInt8 reportId; UInt8 itemIndex;        } BCIInputItemSelection;
// RID 4 (output): host->device scan feedback — THE closed-loop channel (consumed in Plan 02)
typedef struct { UInt8 reportId; UInt8 selectedItem; UInt8 numberOfItems; UInt8 seed;
                 UInt8 itemControlType; UInt8 uiScanningLatencyInt; UInt8 uiScanningLatencyFrac;
               } BCIOutputScanInfoReport;
```

Descriptor header bytes (first bytes — the structural CI gate asserts these): `0x05, 0x60` (Usage
Page = Brain Control Interface), `0x09, 0x01` (Usage = BCI Application), `0xA1, 0x01` (Collection
Application), then `0x09, 0x02` / `0x85, 0x01` (Signal Quality / Report ID 1).

The high-level button-action enum (RID 2 semantics, RESEARCH §1.2): `Select, MoveToNextItem,
MoveToPreviousItem, ToggleAssistiveTechnologyMenu, Activate, StartSequentialNavigation,
StopSequentialNavigation, TriggerAutomation, ToggleAppSwitcher, Home, ToggleNotificationsView,
Assistant, VolumeDown, VolumeUp, ToggleDictation, ToggleAccessibilityFeature, ToggleQuickSettingsView,
Escape, ScrollUp, ScrollDown, ScrollLeft, ScrollRight`.

The gated API (RESEARCH §1.3) — behind #if CORTEX_HID_LIVE only:
- Send input reports: `IOHIDUserDeviceHandleReportWithTimeStamp(device, timestamp, report, size)` —
  timestamp is `mach_absolute_time()`.
- Receive output (scan-info) reports: `IOHIDUserDeviceRegisterInputReportCallback(device, buffer,
  size, callback, context)`.
- Entitlement (the gated key): `com.apple.developer.hid.virtual.device` (Boolean).
- Modern Swift path: CoreHID `HIDVirtualDevice`.

SMAppService (RESEARCH §2): `SMAppService.daemon(plistName:)` → `.register()` → `.status`
(`.notRegistered`/`.enabled`/`.requiresApproval`/`.notFound`), `.unregister()`,
`openSystemSettingsLoginItems()`. macOS 13.0+.
