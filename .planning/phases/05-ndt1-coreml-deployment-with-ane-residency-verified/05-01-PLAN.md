<objective>
Append the **linear velocity readout head** (DEC-10) to the NDT1 encoder so the converted Core ML `.mlpackage` emits a 2-vector `(vx, vy)` fp16 cursor velocity from the last 20ms bin — replacing the Phase-4 96-channel rates output. This is the load-bearing precondition for the entire Phase-5 Swift inference path: the `.mlpackage` shape contract `(1,2,1,1)` fp16 is what Plans 03/04/05 consume. The head is a `1x1 Conv2d(96->2)` fit by closed-form **ridge regression** on the Indy synthetic velocity labels (mirroring Phase-4's dense->Conv2d state-dict hook) — NOT a Kalman filter (ReFIT is Phase 7, Swift-side) and NOT a new training loop.

Purpose: Without `(vx, vy)` output the decoder cannot drive a cursor; this closes DEC-10 and unblocks the Swift side.
Output: `velocity_head.py` (head + ridge fit), an `NDT1ANEWithVelocity` graph in `model_ane.py`, an updated `convert.py` emitting fp16 `(vx,vy)`, and parity evidence (`05-velocity-head-evidence.md`).
</objective>

**`def ridge_fit(rates: np.ndarray, vel: np.ndarray, lam: float = 1.0) -> tuple[np.ndarray, np.ndarray]`** — closed-form ridge:
  - `rates`: `(N, 96)` design matrix (per-bin rates); `vel`: `(N, 2)` velocity labels. Solve `W = (XtX + lam*I)^-1 @ XtY` via `np.linalg.solve(X.T @ X + lam*np.eye(96), X.T @ Y)` -> `W` shape `(96, 2)`; return `(weight, bias)` where `weight = W.T` shape `(2, 96)` (Conv2d `(out,in)` convention) and `bias = Y.mean(0) - (X.mean(0) @ W)` shape `(2,)` (intercept). Raise `ValueError` on shape mismatch (explicit, not bare). Document that fitting on the model's PREDICTED rates (not ground-truth) avoids train/serve skew (Decision 1) — the caller in Task 2 passes predicted rates.
  - Add `def load_ridge(head: VelocityHead, weight: np.ndarray, bias: np.ndarray) -> None`: builds a `state_dict` with `readout.weight` `(2,96)` and `readout.bias` `(2,)` and calls `head.load_state_dict(...)` (the pre-hook unsqueezes the weight). This is the analogue of the Phase-4 dense->conv load path.
