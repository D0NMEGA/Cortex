<objective>
Prove **ANE op-eligibility (DEC-06)** programmatically on the dev Mac: load the compiled `(vx,vy)` model's compute plan via coremltools `MLComputePlan`, scan every operation, and assert that the Neural Engine is in each op's `supported_compute_devices` with **zero CPU-only ops**. This decouples the eligibility proof from iPad hardware (05-RESEARCH TL;DR #1) and is the arbiter for the einsum-attention risk (Decision 6): the scan reveals whether `bchq,bkhc->bkhq` lowers to ANE-eligible MIL ops. The scan runs on the **4-bit palettized** package (the shipping artifact, Risk #5) and emits `residency.txt` + `runtime_plan.json` (meridian convention) for reviewer verification.

**The credibility crux (load-bearing):** this gate asserts ELIGIBILITY only. It MUST NOT assert `preferred_compute_device == neuralEngine` — at ~1.29M params the M5 Mac scheduler may legitimately pick CPU as preferred (the meridian scale trap, Decision 2). Runtime PLACEMENT (DEC-08) is the iPad-M4 HUMAN-UAT artifact (Plan 05). The Mac `preferred` tally is logged as informational, never failed on.

Purpose: Closes DEC-06; gives the reviewer a deterministic, CI-run residency artifact; resolves the einsum question with evidence (and triggers the contingency only if an op falls back).
Output: `compute_plan.py` (the scanner), `test_ane_compute_plan.py` (the slow Mac gate), `residency.txt`/`runtime_plan.json` artifacts, `05-ane-eligibility-evidence.md`, and — CONDITIONALLY — the meridian attention rewrite if and only if an einsum op is not ANE-eligible.
</objective>

```python
import coremltools as ct

# 1) COMPILE first — MLComputePlan needs a .mlmodelc, NOT a raw .mlpackage (Risk #4):
compiled_path = ct.models.MLModel(str(mlpackage_path)).get_compiled_path()
#    (yields the .mlmodelc dir; ct.compile_model(...) is the alternative)

# 2) Load the plan scoped to CPU + Neural Engine:
plan = ct.models.compute_plan.MLComputePlan.load_from_path(
    path=compiled_path,
    compute_units=ct.ComputeUnit.CPU_AND_NE,   # production compute set
)

# 3) Walk every op in main:
program = plan.model_structure.program          # may be None if not an mlprogram -> raise
main_fn = program.functions["main"]
for op in main_fn.block.operations:
    usage = plan.get_compute_device_usage_for_mlprogram_operation(op)   # -> MLComputePlanDeviceUsage | None
    cost  = plan.get_estimated_cost_for_mlprogram_operation(op)         # -> MLComputePlanCost | None
    # usage.preferred_compute_device      : MLComputeDevice
    # usage.supported_compute_devices     : list[MLComputeDevice]
    # device classes: MLCPUComputeDevice | MLGPUComputeDevice | MLNeuralEngineComputeDevice
```
Eligibility test for one op: `any(isinstance(d, ct.models.compute_device.MLNeuralEngineComputeDevice) for d in usage.supported_compute_devices)`.
CPU-only (the regression): `usage is not None and len(supported)==1 and isinstance(supported[0], MLCPUComputeDevice)`.
Ops with `usage is None` (const, etc.) are non-schedulable -> excluded from the eligibility denominator.
