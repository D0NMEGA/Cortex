## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| A hardware measurement -> an agent's judgement | An agent cannot take a device measurement, and approving one for itself fabricates a load-bearing number |
| A Mac number -> an iPad-M4 claim | The project's evidence discipline forbids presenting one as the other; the honest-gates table is where the boundary is declared |
| A recorded demo -> the data it was actually driven by | A GUI that silently fell back to the synthetic source while being recorded as real-data evidence is the demo form of the silent-fallback trap |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
