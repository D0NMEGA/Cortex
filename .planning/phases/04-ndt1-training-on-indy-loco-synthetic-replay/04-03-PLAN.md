<objective>
Implement the NDT1 architecture (Ye & Pandarinath 2021) in the **ANE-conducive BC1S form** (`apple/ml-ane-transformers` principles — 04-RESEARCH.md DEC-01/DEC-04): a non-recurrent Transformer encoder over 20 ms-binned 96-channel spike counts, masked-Poisson reconstruction head, **`nn.Conv2d` (1×1) everywhere instead of `nn.Linear`**, tensors carried as `(B, C, 1, S)` with the sequence axis LAST, single-head-chunked attention using the `bchq,bkhc->bkhq` einsum. Encode the phase's two load-bearing correctness findings as tests:

1. **SC1 — head count must be asserted DIRECTLY.** `nn.MultiheadAttention` param count is INVARIANT to `num_heads` (a h=4 model has identical params to h=2). So SC1 is TWO tests: (a) structural — `num_layers==6`, `d_model==128`, **every attention module `num_heads ∈ {1,2}`**, 20 ms bin semantics; (b) param guardrail `1.0e6 ≤ params ≤ 1.6e6`. (a) is the ONLY thing that catches the h=4 miscitation — see 04-RESEARCH.md §0.1.
2. **SC3 — BC1S enforced with a forward-hook test + negative control.** Hook every activation on a `(1,96,1,S)` dummy pass and assert all are rank-4 with `shape[2]==1`; statically assert ZERO `nn.Linear` on the inference path; a `(B,S,C)` variant must make the test fail (Phase 1/2 trap-bites precedent).

Phase boundary: this is the encoder→predicted-rates forward graph ONLY. NO velocity/(vx,vy) head (DEC-10/Phase 5), NO `ct.convert`/ANE/`computeUnits` (Plan 04-05 does conversion on CPU; ANE targeting is Phase 5).
Purpose: DEC-01 + DEC-04 — the correctly-sized, correctly-laid-out model that training (Plan 04-04) and conversion (Plan 04-05) both consume.
Output: `attention.py` (ANE attention + LayerNormANE), `model_ane.py` (NDT1ANE), `loss.py` (masked Poisson), and the four SC1/SC3 test files.
</objective>
