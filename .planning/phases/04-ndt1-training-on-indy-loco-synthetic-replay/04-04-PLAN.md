## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| checkpoint file (.pt) → torch.load | deserializing a saved model — `torch.load` can execute arbitrary code on a malicious pickle |
| training data → loss/metric | a degenerate dataset could make co-bps meaningless (silent correctness failure) |

## STRIDE Threat Register

> Phase 4 is local single-user offline R&D — no network/auth/external-request surface in this plan. The realistic risks are untrusted-deserialization (`torch.load`) and correctness-integrity of the convergence claim.

| Threat ID | Category | Component | Disposition | Mitigation Plan |

No HIGH-severity threat present.
