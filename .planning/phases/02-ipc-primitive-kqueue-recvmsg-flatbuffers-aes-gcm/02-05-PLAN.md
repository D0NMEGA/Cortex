Implement a self-contained two-thread (or two-process — match the harness form from 02-04-SUMMARY) shm-polled round-trip benchmark. **The timed path MUST be the shm busy-poll + ack-bounce, never the kqueue doorbell (CF#2).**

`public enum Benchmark`:
- `static func runRoundTrip(frames: Int = 200_000, warmup: Int = 1_000) -> BenchResult`:
  - Create the ring (`ShmRing(create: true)`). Spawn a CONSUMER thread via raw `pthread_create` (NOT a Swift Task — keep the measured path off the cooperative runtime, consistent with the project's audio-callback discipline). In the consumer thread FIRST call `pthread_set_qos_class_self_np(QOS_CLASS_USER_INTERACTIVE, 0)`, then busy-poll `ring.pollLatest(...)` and immediately `ring.ack(seq:)` for each new seq.
  - On the producer (main) thread also `pthread_set_qos_class_self_np(QOS_CLASS_USER_INTERACTIVE, 0)`. For each of `frames` iterations: `let t0 = Time.machAbsoluteNanoseconds()`; `let seq = ring.write(slotBytes:)`; busy-poll `ring.pollAck(lastSeen:)` until it returns `seq`; `let t1 = Time.machAbsoluteNanoseconds()`; record `t1 - t0` into a preallocated `[UInt64]` (preallocate to avoid allocation on the timed path).
  - Discard the first `warmup` samples. Compute p50, p99, σ (sort for percentiles; σ = sqrt(mean((x-μ)^2))). Return `struct BenchResult { let n: Int; let p50ns: Double; let p99ns: Double; let sigmaNs: Double; let rawSamples: [UInt64] }`.
  - Do NOT use AES-GCM in the timed loop body (D-01: crypto is OFF the measured doorbell path; the benchmark measures transport round-trip, encrypt/decode is a separate ~200-400ns cost the SUMMARY notes). The slot payload can be a fixed dummy of the correct stride.
- `static func writeHistogram(_ r: BenchResult, to path: String)`: bucket rawSamples (e.g. 50ns buckets) and write a text histogram + a CSV of raw samples next to sc1-evidence.md.
- A `main`-reachable hook: extend `Apps/CortexDaemon/main.swift`'s mode switch (from Plan 02-04) with a `"bench"` mode that calls `Benchmark.runRoundTrip()` and prints + writes the histogram. **Important (CF#2 enforcement):** add a top-of-file comment AND ensure the timed loop contains NO `Doorbell`/`kevent`/`recvmsg` call — the doorbell is the idle wake, measured separately if at all.
