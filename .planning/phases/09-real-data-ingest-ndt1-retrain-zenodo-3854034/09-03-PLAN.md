
`num_bins == int(np.floor((t_end - t_start) / 0.020))` (`ndt1.data.bin_spikes`), and `BIN_MS = 20.0`.

The readout geometry this must align to (`ndt1.velocity_head.VelocityHead.forward`):

```python
def forward(self, rates: Tensor) -> Tensor:
    last = rates[..., -1:]        # STATIC slice of the LAST bin of the window
    return self.readout(last)     # 1x1 Conv2d(96 -> 2)
```

So "lag k" pairs the window ENDING at bin `i` with the velocity at bin `i + k`.

The existing closed-form fit, unchanged by this plan (D-09):

```python
def ridge_fit(rates: np.ndarray, vel: np.ndarray, lam: float = 1.0
              ) -> tuple[np.ndarray, np.ndarray]:  # -> (weight (2, 96), bias (2,))
def load_ridge(head: VelocityHead, weight: np.ndarray, bias: np.ndarray) -> None: ...
```

7 bins at 20 ms. `mc_maze` uses 100 ms, `area2_bump` uses -20 ms. Independent corroboration: M1
activity leads hand velocity by 120-180 ms (PNAS 10.1073/pnas.2212227120).

Add to `kinematics.py`:

```python
def heldout_r2(y_true: np.ndarray, y_pred: np.ndarray, train_mean: np.ndarray
               ) -> dict[str, float]:
    """Held-out R2 of a velocity readout against a CONSTANT TRAIN-MEAN null (D-10).

    R2_axis = 1 - SS_res / SS_tot  where
      SS_res = sum over TEST bins (y_true - y_pred)^2
      SS_tot = sum over TEST bins (y_true - train_mean)^2

    The null mean MUST come from the TRAIN split, mirroring co_bps's train-split mean-rate null.
    Using the test set's own mean turns SS_tot into the test variance and silently converts this
    into the easier textbook R2 -- a different claim. This is what replaces velocity_r2.json's
    0.9998, which regressed rates onto labels generated from those same rates.

    Returns:
        {"vx": float, "vy": float, "pooled": float, "n": int} where "pooled" is
        1 - sum_axes SS_res / sum_axes SS_tot (NOT the mean of the per-axis values -- the axes can
        carry different variance).
    """
```

Validate: both arrays 2-D with shape `(n, 2)` and equal `n`; `train_mean` shape `(2,)`. Raise
`ValueError` naming the offending shape. Raise `ValueError` if any per-axis `SS_tot == 0.0`
("the held-out signal on axis {i} is constant; R2 against a mean null is undefined"). Do NOT clamp a
negative result - a readout worse than the null is a real, reportable finding under D-25.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `finger_pos` / `t` arrays -> velocity labels | An untrusted behavior clock or position array becomes the supervision signal for the shipped readout; a silent NaN or misalignment here becomes a published R2 |
| TRAIN split -> held-out score | The boundary that makes the number honest; any leak of test statistics into the null or the lag selection invalidates the claim |
